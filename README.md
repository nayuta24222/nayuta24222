# Delete Me Not.

最下層を舞台にした固定画面型ポイント＆クリック「記憶改変メタサスペンスRPG」のプロトタイプ。
ビルド不要の静的 HTML / CSS / JavaScript 構成。

## 起動方法

```bash
# リポジトリ直下で任意の静的サーバーを起動
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

`index.html` をダブルクリックしても動作します（画像はCDN読み込みのためネット接続が必要）。

## 実装済みシステム

| システム | 内容 |
| --- | --- |
| タイトル画面 | グリッチロゴ / LOOP_COUNT表示 / ED5達成後は特殊仕様に変化 |
| 探索ステート | 俯瞰ドット絵マップ＋透過ミニキャラ配置。矢印(◀▶▼)・赤点・◈が移動/調査の指標 |
| 階層マップ | ミニマップ(右下)で主要エリア移動、マップ内の矢印・赤点で奥エリアへ |
| イベントステート | 話しかけると立ち絵＋タイピング風テキスト＋選択肢 |
| パラメーター | タバコ(行動回数)/レイの依存度/世界の違和感/汚染度 |
| メタセーブ | 3スロット。ロードでLOOP_COUNT+1・違和感上昇・画面グリッチ |
| QTE | WASD 1.5秒判定。失敗で汚染度+15%・赤フラッシュ |
| バトル | ターン制コマンド。汚染度で最大HP減。敵HP30%以下で対話モード(モノクロ演出) |
| 章進行 | 全5章。章ごとにマップ解放/封鎖。タバコ切れで強制イベント |
| メタ演出 | 違和感20%/50%/80%/100%でテキスト文字化け→UI振動→セーブ画面破損表示→UI消失 |
| エンディング | ED1〜5 判定エンジン（優先順位式）。ED3は疑似クラッシュ、ED1はステータス初期化 |
| 音響 | WebAudioによるプロシージャル生成（雨・環境音・エリア別BGM・SE全種） |

## エンディング条件（優先順）

1. **ED5 共犯者の檻**: 違和感100% ＆ 依存度100% ＆ 破損ファイル5個解析済
2. **ED4 代理人形の復讐**: LOOP_COUNT≧5 ＆ 依存度≦10%
3. **ED3 世界の拒絶**: 違和感≧80% で最終対話「お前はデータだ」を選択
4. **ED2 完全なる機能停止**: 汚染度100%
5. **ED1 忘却の融解**: 上記以外

## アセットについて

- **キャラクター（ドット絵・立ち絵）**: `assets/sprite/` `assets/tachie/` にローカル同梱（背景透過済み）
- **背景・バトル敵**: Higgsfield生成のCDN URLを参照（`js/data.js` の `ASSETS` に集約）
- サク・ケイは演出としてシルエット＋グリッチ表現、UNIT-09は廃棄ドック背景内の頭部ユニットをホットスポット化

## 進行形式

進行単位は「日」（1日目〜最終日）。`js/data.js` の `CHAPTERS` にエントリを足すだけで日数・マップ解放・目標を拡張できます。
セーフハウスのPC端末では セーブ/ロード/破損ファイル解析 に加え、**敵データベース（図鑑）** と **アイテム記録（詳細ロア）** が閲覧できます。

## デスクトップ版（ダウンロード配布用）

Electronでスタンドアロンのソフトとして起動・配布できます。

```bash
cd desktop
npm install          # 初回のみ（electron / electron-builder）
npm start            # そのまま起動して動作確認

# 配布用ビルド（Windows: ポータブルexe + インストーラ）
./sync-app.sh        # ゲーム本体を desktop/app/ に同期
npm run dist:win     # → desktop/dist/ に出力（mac: dist:mac / linux: dist:linux）
```

※画像アセットはCDN参照のため、現状はデスクトップ版でもネット接続が必要です。
完全オフライン化する場合は assets/ にダウンロードして `js/data.js` のURLを差し替えてください。
